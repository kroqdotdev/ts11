# Security policy

## Reporting a vulnerability

Please report security problems privately, through GitHub: **Security → Report a vulnerability**
on this repository. Don't open a public issue.

Include what an attacker could do, the steps to reproduce it and the affected URL or code. You'll
get an answer within a few days. Once it's fixed, you're welcome to be credited in the release
notes.

## Scope

In scope: teamsheet11.com and the code in this repository, in particular accounts, sign-in,
club sync and image uploads.

Out of scope: rate limits being reachable with enough effort, reports from automated scanners
without a demonstrated impact, and social engineering.

Please don't access other people's data, run denial-of-service tests against teamsheet11.com, or
send large amounts of mail through the sign-up form. Use your own accounts for testing.
